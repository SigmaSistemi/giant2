Applicazione Giant2 (client installato)

Giant2 è un software gestionale che opera in locale o in rete aziendale: si collega esclusivamente al database del cliente (SQL Server / rete interna) per la gestione dei propri dati aziendali. Il programma non invia alcun dato a Sigma Sistemi né a server esterni, non effettua raccolta di telemetria e non richiede connessione internet per il proprio funzionamento ordinario.

Il trattamento dei dati inseriti nel gestionale (anagrafiche, dati contabili, ecc.) è di esclusiva competenza del cliente, in qualità di titolare del trattamento dei propri dati aziendali.

Dati raccolti (sito web)

Questo sito non raccoglie dati personali identificativi. È utilizzato il servizio di analytics privacy-friendly GoatCounter per conteggiare in forma aggregata e anonima le visite e i download, senza cookie né tracciamento individuale.

Hosting

Il sito è ospitato su GitHub Pages. GitHub può raccogliere dati tecnici (es. indirizzi IP) nei propri log di sistema. Per dettagli, consulta la Privacy Policy di GitHub.
